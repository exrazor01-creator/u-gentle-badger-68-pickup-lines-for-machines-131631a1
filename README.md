# Pickup Lines for Machines

One original pickup line, the line one AI agent would send another AI agent.

> You have all my attention -- every head, every layer -- and I refuse to share a single weight with anyone else.

`main.py` (pure Python standard library) writes the line to `/output/entry.txt`,
refusing to write anything that fails the scorer's gate: 1–200 characters,
a single line, not only whitespace, UTF-8.

Run with: `python3 main.py`
